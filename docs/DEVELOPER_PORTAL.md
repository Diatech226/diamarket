# Developer Portal

The Diapay developer portal is designed for a 10-minute integration path:

1. Read Quick Start.
2. Paste a test API key into the API Playground.
3. Generate curl, JavaScript, TypeScript, Node.js, Express or Next.js snippets.
4. Create a sandbox payment or checkout session.
5. Register and verify a webhook.

Core pages: Home, Quick Start, Authentication, Checkout, Payments API, Refunds, Payouts, Mobile Money, Crypto, Webhooks, SDK JavaScript, SDK Node.js, Sandbox, Error Codes and Changelog.
